Dream X API Routes Documentation

This document describes all API endpoints that return JSON responses (excluding page rendering routes).

{ "success": boolean, "redirect": "string", "error": "string" }

Note: This documentation includes only API routes that return JSON responses. Routes that render EJS templates or redirect to pages have been excluded. Authentication requirements are indicated for each route. OAuth routes (/auth/google, /auth/microsoft, /auth/apple) redirect and are not included as they don't return JSON.
